# The guide — ten language editions

The Eight Essentials guide is published online in ten languages, and
each edition has an offline pack: a single download with every page,
the audio, the fonts and the images inside, so it works with no
internet at all.

The agent teaches from the lesson files in this repo
(`essentials/01..08/lessons/`), branched to the student's tradition.
The editions below are for reading and sharing — the published
Universal edition text, one page and one download per language.

## For the agent

- The student's language is captured at onboarding and stored as the
  `language` memory key (default `en`).
- Write every student-facing message, lesson and check-in in that
  language. The lesson files are in English; teach in the student's
  language.
- When the student asks to read the guide, or during setup, share
  their language's row above: the read-online link, and the offline
  pack when the household has limited internet.
- If the README exists in the student's language (`README.<code>.md`
  at the repo root), point to it for setup reading.

## Both traditions

Every chapter in this repo carries both editions as separate files
(`christian.md` and `universal.md`), and the agent branches on the
student's tradition — never mixing. The ten published editions above
are the Universal edition text, translated; a student on the
Christian path still gets every lesson from `christian.md`.
